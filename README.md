# Индустриальный гид — WebAR-платформа для промышленных экскурсий

## О проекте

**Цель проекта** — создать удобную цифровую платформу для промышленных предприятий, туроператоров и образовательных учреждений, которая позволяет быстро и без привлечения дорогостоящих разработчиков создавать иммерсивные AR-экскурсии с 3D-анимациями, интерактивными мини-играми и викторинами, а также отслеживать вовлечённость посетителей в реальном времени.

Проект решает проблему низкой вовлечённости на стандартных экскурсиях, сложности создания современного технического контента (3D-модели оборудования, анимации технологических процессов), отсутствия инструментов монетизации и измерения эффективности экскурсионной деятельности.

### Как это работает

Пользователь (турист, школьник или студент) сканирует QR-код на входе на предприятие или открывает приложение «Индустриальный гид». На экране смартфона поверх реального оборудования отображаются 3D-модели, анимированные схемы, архивные фотографии и аудиосправки. В ключевых точках маршрута предлагаются интерактивные механики: мини-игры, викторины, AR-селфи. По завершении экскурсии система выдаёт цифровой сертификат, а все материалы сохраняются в личном кабинете.

## Реализованный функционал

### 🖥 Backend (Express + SQLite)

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `/api` | GET | Информация об API |
| `/api/enterprises` | GET | Список предприятий |
| `/api/enterprises/:id` | GET | Детали предприятия |
| `/api/enterprises/:id/routes` | GET | Маршруты предприятия |
| `/api/routes/:id` | GET | Маршрут с точками |
| `/api/routes/:id/points` | GET | Точки маршрута |
| `/api/session/start` | POST | Начало сессии |
| `/api/session/:id` | GET | Данные сессии (с названием маршрута и предприятия) |
| `/api/session/:id/progress` | GET | Прогресс экскурсии |
| `/api/session/:id/visit` | POST | Отметка посещения точки |
| `/api/session/:id/complete` | POST | Завершение + сертификат |
| `/api/games/:pointId` | GET | Данные игры |
| `/api/games/:pointId/result` | POST | Сохранение результата |
| `/api/auth/*` | ALL | Регистрация, вход, выход, профиль |

### 🎨 Frontend (React + Vite + Tailwind)

#### Страницы
- **Лендинг** (`/`) — Hero с фоновым изображением, блок "Как это работает", тарифы, форма заявки
- **Вход** (`/login`) — форма авторизации с демо-данными, редирект по ролям
- **Выбор маршрута** (`/start/:enterpriseId`) — ввод имени, выбор маршрута
- **AR-тур** (`/tour/:sessionId`) — 3D-превью точек маршрута (левая панель 300px + 3D-область), прогресс-бар, кнопки "Подробнее / Играть / Отметить"
- **Игры** (`/game/:sessionId/:pointId`) — динамическая загрузка по типу
- **Завершение** (`/complete/:sessionId`) — конфетти, очки, сертификат (PDF с кириллицей)
- **Enterprise-панель** (`/enterprise-panel`) — управление маршрутами
- **Админ-панель** (`/admin-panel`) — пользователи, статистика

#### Игры (4 типа)

| Точка | Игра | Тип | Описание |
|-------|------|-----|----------|
| 🔥 Доменная печь | Викторина | `quiz` | 3 вопроса с таймером, объяснения |
| ⚙ Прокатный стан | Пазл 3×3 | `assembly` | Собрать изображение pic.jpg из 9 фрагментов |
| 🪖 ОТК-стенд | Контроль качества | `quality` | 5 деталей (реальные PNG), определить брак |
| 🏁 Финальный стенд | Поймай детали | `catcher` | Ловить ⚙️🔩🔧🏗️, избегать 💣🗑️❌, комбо-система |

#### Компоненты UI
- **Toast** — уведомления (slide-down, автоскрытие)
- **BottomSheet** — выдвижная панель снизу
- **ProgressBar / ProgressBadge** — индикатор прогресса
- **AR3DPreview** — 3D-превью через Three.js (6 типов: furnace, gear, soldier, horse, robot, cube)
- **ARInstructions** — инструкция по AR
- **ApplicationModal** — форма сбора заявок

### 🎮 CatcherGame (Поймай детали)
- Игровое поле на весь экран
- Управление мышью (глобальные обработчики — работает при выходе за край)
- Хорошие детали (⚙️🔩🔧🏗️) → +10 очков
- Плохие детали (💣🗑️❌) → -15 очков
- Комбо-система: каждые 3 поимки подряд ×1.5, ×2.0, ×2.5...
- Медали: 🥇≥200, 🥈≥100, 🥉<100
- Таймер 45 сек

### 📄 Сертификат
- Генерация через HTML → html2canvas → jsPDF (кириллица работает)
- Данные: имя, маршрут, предприятие, баллы, дата
- QR-код (заглушка)

### 🔐 Авторизация
- JWT в httpOnly cookie
- Регистрация enterprise/admin (по invite-коду)
- Роли: admin, enterprise
- Защищённые маршруты: `/admin-panel`, `/enterprise-panel`

### 🗄 База данных (SQLite)
- 2 предприятия: МеталлПром, ТекстильПлюс
- 2 маршрута: "Рождение металла" (4 точки), "Путь нити" (3 точки)
- 3 пользователя: admin, 2 enterprise-менеджера
- Автоинициализация и seed при первом запуске

### 🐳 Инфраструктура
- Docker multi-stage build (Node 20 Alpine)
- .dockerignore
- entrypoint.sh — автоинициализация БД + seed
- Статические ассеты: A-Frame, AR.js, 3D-модели (.glb), маркеры (.patt), изображения

## Планируемый функционал

### 📌 Высокий приоритет
- **QR-сканер** — сканирование QR-кода для входа в экскурсию (замена прямого URL `/start/1`)
- **Marker-based AR** — привязка `.patt` маркеров к точкам маршрута, реальная AR-камера через A-Frame + AR.js
- **Загрузка 3D-моделей** — динамическая загрузка `.glb` моделей с сервера для каждой точки
- **Реальный QR на сертификате** — генерация QR-кода через библиотеку qrcode

### 📌 Средний приоритет
- **PostgreSQL** — замена SQLite для продакшена
- **CI/CD** — GitHub Actions: сборка, тесты, деплой
- **WebSocket** — real-time обновления прогресса экскурсии
- **Email-уведомления** — отправка сертификата на email (nodemailer)
- **Аудиогид** — воспроизведение аудио на точках маршрута
- **Адаптация под мобильные устройства** — responsive layout

### 📌 Низкий приоритет
- PWA (service worker, оффлайн, манифест)
- Тёмная тема / настройка внешнего вида
- Мультиязычность (en/de)
- Интеграция с CRM / системами бронирования
- Аналитика (Яндекс.Метрика / Google Analytics)
- Image resize (sharp) для загруженных изображений
- Rate limiting под нагрузкой
- Мониторинг (Prometheus + Grafana)

## Быстрый старт

### Локальный запуск

```bash
# 1. Установить зависимости
cd server && npm install
cd ../client && npm install

# 2. Инициализировать БД
cd ../server && node src/db/seed.js

# 3. Запустить сервер (терминал 1)
cd server && node src/index.js

# 4. Запустить клиент (терминал 2)
cd client && npm run dev

# 5. Открыть в браузере
# http://localhost:5173
```

### Docker запуск

```bash
docker-compose up --build
# http://localhost:3000
```
